NC1 ke G-code F2100B

NC1 → G-code F2100B

Upload file DSTV NC1 (plat dari Tekla / nesting), lalu simpan file .TXT untuk flashdisk mesin CNC MiniCut. Lubang dipotong dulu, kontur luar terakhir, dengan kompensasi kerf G41.

Seret file .nc1 ke sini Boleh beberapa file sekaligus. File diproses di browser ini, tidak dikirim ke mana pun.

Pengaturan

Di mesin

  1. Salin .TXT ke root flashdisk, colok ke mesin.
  2. F2 Files → F2 UDisk → pilih file → F6 simpan ke internal.
  3. F1 DiskFile → pilih → F7 Preview → F8 OK.
  4. Geser torch dengan tombol panah ke pojok kiri bawah plat. Posisi ini menjadi titik nol (X0 Y0), karena program diawali G92X0Y0.
  5. Space → F3 Frame dan dry run tanpa api, lalu Start.

Part diletakkan sejauh Offset X / Y dari titik nol (default 15 mm), jadi torch harus berada di dalam plat minimal sejauh itu dari tepi.
